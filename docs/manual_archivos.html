Cómo funcionan los Archivos

Subir, guardar, previsualizar y compartir archivos de forma segura, sin que ninguno pueda ejecutarse ni poner en riesgo tus datos.

1. Qué son los Archivos

La sección Archivos es tu almacén personal dentro de SecureDoc: subes documentos, imágenes, PDFs, etc., los organizas en repositorios (como carpetas) y, si quieres, los compartes con un enlace. Todo queda bajo tu cuenta.

Idea central: un archivo aquí es siempre contenido para ver o descargar, nunca algo que se ejecute. Aunque subas una página web o un script, SecureDoc lo trata como texto inofensivo.

2. Repositorios: públicos y privados

Un repositorio agrupa archivos relacionados. Cada uno puede ser:

  • Privado: solo tú, con tu sesión iniciada, puedes verlo. Es la opción por defecto.
  • Público: cualquiera con el enlace puede abrir los archivos, sin cuenta. Útil para compartir, pero piensa bien qué pones aquí.
Puedes empezar en privado y hacerlo público solo cuando lo necesites. Lo público es visible para quien tenga el enlace, así que no subas ahí información sensible.
dónde se registran tus repositorios

La lista de repositorios (fileRepos) se guarda en tu propio documento de usuario (users/{uid}). Los archivos en sí se almacenan en el almacenamiento de SecureDoc y se referencian desde ahí; el acceso público/privado se decide por la marca del repositorio y por tu sesión.

4. Subir, paso a paso

  1. Entra en Archivos y elige (o crea) el repositorio donde quieres guardar.
  2. Pulsa Subir y selecciona el archivo desde tu equipo.
  3. SecureDoc comprueba el tamaño (hasta 25 MB) y el tipo. Si algo no encaja, te lo dice al momento.
  4. El archivo queda guardado en el repositorio, con su nombre y fecha. Listo para verlo, descargarlo o compartirlo.
El límite por archivo es 25 MB. Para vídeos o archivos muy grandes, comprime o usa un servicio pensado para ello.

5. Previsualizar sin riesgo

Puedes ver muchos archivos sin descargarlos:

  • Imágenes (incluido SVG): se muestran como imagen.
  • PDF: se abre en el visor.
  • Texto y código (incluido HTML o JavaScript): se muestra como texto, nunca se ejecuta.

Para archivos de texto muy largos, la vista previa muestra los primeros 200.000 caracteres para no saturar el navegador; el archivo completo sigue disponible al descargar.

cómo se neutraliza el contenido activo

Un SVG puede llevar scripts, así que se muestra dentro de una etiqueta <img> (que no ejecuta scripts), no incrustado en la página. A los PDF se les fuerza el tipo MIME correcto para que el navegador los trate como documento. El HTML/JS se vuelca como texto plano (escapado), de modo que las etiquetas se ven como caracteres y no como código. El resultado: el contenido nunca corre en el contexto de SecureDoc.

6. Compartir con enlace y QR

Si el repositorio es público, cada archivo puede compartirse con un enlace y su código QR (cómodo para abrirlo desde el móvil). Quien reciba el enlace ve el archivo sin necesidad de cuenta.

El QR es solo una forma visual del mismo enlace. Si cambias el repositorio a privado o borras el archivo, el enlace deja de funcionar.

7. Caducidad y limpieza

Los archivos públicos pueden tener caducidad automática: pasado un tiempo, se retiran solos para que no queden enlaces abiertos indefinidamente. Así mantienes tu almacén ordenado y reduces exposición.

Tus archivos privados no caducan solos: se quedan hasta que tú los borres. La caducidad aplica a lo que compartes en público.

8. Por qué es seguro

Resumen de las protecciones que trabajan por ti:

ProtecciónQué evita
El contenido nunca se ejecutaQue un archivo subido (SVG, HTML, JS) corra código o robe datos.
SVG como imagen y HTML/JS como textoScripts ocultos dentro de un archivo “inofensivo”.
PDF con tipo forzadoQue el navegador interprete mal el archivo.
Límite de 25 MBSubidas enormes que saturen tu almacén.
Privado por defectoCompartir algo sin querer.
Caducidad de lo públicoEnlaces abiertos para siempre.
Regla práctica: trata lo privado como tu cajón personal y lo público como un tablón a la vista. Sube a público solo lo que no te importe que vea cualquiera con el enlace.
